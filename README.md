# Sachin Kadannavar Portfolio

## Run in VS Code
1. Unzip, then File > Open Folder > sachin-portfolio
2. Install the "Live Server" extension
3. Right-click index.html > Open with Live Server

## Files
- index.html, style.css, script.js: portfolio website
- photo.jpg: your photo (replace with another image of the same name)
- avatar-poster/index.html: 3D rotating avatar poster (open separately)

## Edit your info
- Hero titles and text: index.html (".words" and the "sub" array in script.js)
- Projects: the .pj cards in index.html
- Colors: :root variables at the top of style.css
